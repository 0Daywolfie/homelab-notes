# Homelab Notes

Documentation of my personal cybersecurity/networking homelab build — setup steps, configs, and troubleshooting logs.

## Environment
- Host: Linux Mint (HP Pavilion 14)
- Virtualization: VirtualBox
- VMs: Whonix Gateway + Workstation, Kali Linux, Windows Server, vulnerable target boxes

## Structure
- `networking/` — network config, VPN, remote access setup
- `virtualbox/` — VM build and configuration notes
- `scripts/` — automation scripts
- `fixes/` — documented issues and how I solved them
